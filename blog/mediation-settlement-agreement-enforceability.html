调解与和解协议怎么写才执行得动:三种纸的区别、给付条款的确定性与加速到期(2026)

面向律师 / 法务 / 争议解决团队 · 2026 更新

「案子调解结了」常被当成办完了。但当事人回头找上来的,往往正是这一类:调解书签了、和解协议签了,对方一分钱没给,手上这份纸执行不动。失手位置高度集中在三处——签的是哪种纸没分清、给付条款不确定、分期没有加速到期,而三处都发生在落笔那十几分钟里,事后无法补救。本文讲清三种纸的可执行性差别、给付条款的四项要素与六个不能用的表述、分期与担保条款的落笔方法,以及只用公开裁判文书时检索能提供什么。程序表述按通行理解归纳,具体效力、程序与期限以现行有效法律及受理法院的要求为准,不构成法律意见。

一、先分清签的是哪一种纸

「调解」在日常说法里混着三样不同的东西,区别不在名称,在对方反悔那天这份纸能不能直接用。

法院民事调解书诉前调解 + 司法确认纯当事人和解协议
对方不履行怎么办直接申请强制执行确认裁定已拿到,效果与前者近只能另行起诉或仲裁,先拿新裁判
性质执行依据执行依据(以裁定为准)合同
最常见的失误条款不确定,执行阶段才发现只签了协议、确认程序没走完把它当成第一种在用

第三列代价最大:谈判时双方都觉得解决了,反悔后才发现要从头打一场官司,而可保全的财产往往已经不在——这也是和解要与 财产保全 一起考虑、而非二选一的原因。

一句最实际的话:决定用哪种纸,不看谈得多顺,看假设对方明天反悔,你希望手上是什么。

二、给付条款的确定性:执行法官不需要再判断任何事

可执行性可压成一句话:执行法官拿到这份纸,不需作任何额外判断就能算出金额、认定期限、找到主体。四项要素缺一不可。

要素必须写到什么程度写不到会怎样
谁给谁主体全称与身份信息;义务人之间连带还是按份必须写明只能向签字一方主张,其他人不受约束
给多少本金、利息、违约金分别列明,不能只给一个合计数违约金基数无从计算
什么时候给具体日期,不用相对表述是否违约本身成为争点
怎么给付到哪个账户、何种交付方式;需对方配合的动作由谁何时完成互相等对方先动,谁都不算违约

下面六个表述在谈判桌上最容易让双方同时点头——恰恰因为谁都没被真正约束住,也是执行阶段争议的高发来源:

不要写改成
尽快支付 / 及时支付于某年某月某日前支付
视经营情况支付固定期限 + 逾期的具体后果
待项目结算后支付约定最迟付款日,结算只作提前付款的触发条件
双方另行协商确定现在就定;定不了的明确不在本协议范围内
支付相应利息 / 按银行同期利率写明起算日、计算基数、计算方式
履行完毕后办理相关手续列明手续名称、办理方、期限与不办理的后果

核对这几行的思维与列 举证清单、写 质证意见 相同:假设对面要挑毛病,这句能不能被读成另一个意思。

三、分期付款:没有加速到期,分期就是免费的时间

分期是调解里最常见的让步。但若只写「分若干期、每期多少、各期到期日」,对方不付第一期时你能主张的通常只有已到期的那一期,剩下几期各自等到期,债权人被迫多次进执行程序,对方拿到了完整的时间。

加速到期条款把这件事反过来:约定任何一期未按期足额支付,全部剩余款项即时到期,可就全部余额一次申请执行。配套三处必须一起写:

  • 违约后的计息起点与基数:从哪天起算、按什么基数、怎么计算。缺了它,加速到期只加速了本金。
  • 部分支付算不算按期履行:写明「未足额」同样触发,否则对方每期少付一点,是否违约都能吵。
  • 尾款比例别留太大:最后一期占比过高时,对方会把前面几期当成购买时间的成本。
一个反直觉的取舍:金额上多让一点,换来期数更少 + 加速到期 + 计息起点写死,通常比金额顶满而条款松散划算得多——前者违约即面对全部余额,后者拖着都不痛。

四、最常缺的三块:担保、违约成本、范围条款

这三块不影响「谈成」,只影响「拿到钱」,因此最常在收尾阶段被省掉。

  • 担保与连带责任。由实际控制人或关联公司连带、或提供财产担保,是分期方案里最有效的一块。要点是担保人必须在同一份文件上签署,并写明担保范围(是否覆盖违约金与实现债权的费用)与担保期间;另附担保书而调解书里不提,执行阶段易出争议。
  • 违约成本。只写「逾期应承担违约责任」等于没写,要落到可计算:起算日、基数、计算方式与上限表述。
  • 范围条款。「一次性解决双方全部争议」双方理解常常不同——是否包含其他关联案件、其他主体、尚未发生的同类争议、是否放弃另案主张。范围写宽的一方要清楚自己放弃了什么,这一句事后的分量常超过金额条款。

五、执行阶段的和解,不是审判阶段的调解

这是实务中最常被弄错的一处,代价直接落在能不能拿到钱上。

审判阶段调解执行程序中的和解
产出调解书 = 新的执行依据通常不产生新的执行依据
对方不履行直接申请执行调解书申请恢复执行原生效裁判
落笔要注意确定性、加速到期、担保别把原判决债权作实质置换,不写可被读成放弃的表述

稳妥写法是明确:和解不影响原生效裁判的效力,仅在对方按约履行完毕的前提下不再主张剩余部分。反之若把原债权「换成」一份新的付款安排,对方不履行时恢复执行的范围就成了争点——而此时已错过 执行阶段 最有价值的时间窗。

相邻风险是撤诉换和解:撤诉后手上只剩一份合同,回到第一节表格的第三列。对方资信不明或付款周期较长时,宁可要一份调解书。

六、检索能给什么:三类文书要分开查

调解看起来「没有类案可查」,可查的东西其实相当具体,只是三类文书性质不同,混着查会得到互相矛盾的印象。

查什么用途怎么用
同类纠纷的调解书 / 含和解条款的文书看给付、加速到期、担保范围这些句子通常怎么落笔当模板参考,引用前必须回原文核对
不履行后的执行裁定、执行异议裁定看争议实际集中在哪几个条款上经验上高度集中在给付内容是否确定与加速到期是否成立
主张撤销调解书 / 调解协议无效 / 和解效力争议的判决看法院对争点的分界表述把支持与不支持的理由抄成两栏,反过来当自查清单

第三类的读法与二审再审同理:抄事实要素与分界表述,不抄结论(见 二审和再审怎么找改判点)。这类争点多为要素组合,关键词召回常不准,差别见 语义 vs 关键词检索;查到什么程度算查全见 类案检索查全。

谈判前还值得把对方的涉诉记录一次调出来。用处不是「查资产」,而是判断三件事:有无大量在先债务、是否已有其他债权人进入执行、以及它作为原告有没有生效给付判决(那是它对第三人的到期债权,可直接写进担保或抵扣安排)。检索动作与 代理词 阶段相同,只是目标从说服法官换成设计条款。

七、一条红线:调解履行率、成功率,一个都不能写

做完检索很容易想给当事人一句「这类案子调解一般都能履行」。这个数不能给,它错的方向还特别隐蔽。

  • 分母双向都是错的。大量调解书不以公开裁判文书形式出现;更关键的是按约履行完毕的案件通常不产生任何后续文书,直接被排除在样本外。能检索到的多是走到执行、异议或撤销的那一部分,算出的履行率系统性偏低。
  • 结果取决于对方当下的偿付能力。与同类案件历史上怎么履行几乎无关,与条款怎么写、有没有担保关系更大。
  • 当事人会把它记成承诺。「一般都能拿到」在对方违约那天会被原话复述回来。

替代表述是描述性的:「检索范围内纳入 M 份此类文书,争议多数集中在给付期限表述不确定;另有若干份不支持加速到期主张,区分点在是否写明未足额支付同样触发。」——写明范围、篇数与相反口径。这与 财产保全 的成功率、执行阶段 的执行到位率是同一条红线;量化边界见 律师工作台。

八、系统能做到哪一步,哪一步不能

界线与本系列前几篇一致:错了当场能发现的可以交给工具,错了要到很晚才暴露的不能。调解的特殊风险正是暴露极晚——条款写松了,往往要到对方违约那天才知道,那时已无法修改。

可以交给系统的永远由人做的
按案由与文书类型收窄,批量调出同类调解书与含和解条款的文书,留检索式与日期判断用哪种纸、让到什么程度、要不要担保
抽取执行裁定与撤销类判决中的分界表述,做成支持 / 不支持对照表初稿把对照表转成本案条款与自查清单
按当事人调出全部涉诉文书,分原告 / 被告身份,识别在先债务与到期债权核对主体同一性,判断偿付能力与筹码
生成条款草稿(给付 / 加速到期 / 担保 / 范围)与逐条自查清单逐字定稿,确认没有可被读成两种意思的句子

硬规矩:凡写进调解方案、和解协议与执行申请的案号、法院、裁判日期与引用原句,必须回原文逐条核过。模型为何能把引文编得像真的,见 引证核验;卷宗侧边界见 AI 阅卷;留痕字段表见 类案检索报告。

九、定稿前自查与常见坑速查

签字前跑三步:①把条款交给不了解案情的人读,问他「谁在哪天该给多少、给不到怎么办」,答不上来就是写松了;②假设对方明天违约,逐条走一遍从申请执行到拿到钱的路径,看卡在哪;③确认签的是哪种纸、程序是否真的走完。最常踩的坑:

  • 把纯和解协议当成执行依据 → 反悔后从头打官司,财产往往已不在。
  • 诉前调解只签了协议,司法确认没走完 → 手上仍是合同。
  • 分期没有加速到期 → 分期变成免费的时间,还得多次进执行。
  • 只写合计金额不写构成 → 违约金基数无从计算。
  • 「双方另行协商」「待结算后」 → 到期日本身成为争点。
  • 担保另附一份、调解书里不提 → 执行阶段容易出争议。
  • 执行和解里把原债权作实质置换 → 恢复执行范围会有争议。
  • 给当事人一个履行率 → 分母双向错,还会被当成承诺。
