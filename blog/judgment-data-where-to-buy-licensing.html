裁判文书数据哪里可以买到？数据授权找谁？

2026-09-22 · 文书查 · 面向法律科技公司 / 律所与政法机关信息化 / 研究机构

一句话答案：中国裁判文书网只提供公开查阅，目前没有对外出售批量数据或 API 的公示渠道；要合规拿到批量裁判文书数据，途径是向商业法律数据库或数据服务商签数据授权合同，签约前用本文第五节的 8 项口径逐项核验。

这篇写给三类人：要给法律 AI 产品找训练与检索语料的技术负责人、要为本所或本单位采购数据的信息化负责人、以及做实证研究需要成批文书的老师和学生。我们自己就是卖数据授权的一方，所以下面会把我们能给什么、给不了什么放在同一张表里写清楚，也会把你该拿去问所有供应商（包括我们）的问题列出来。

本文三个结论
  1. 市面上所有「裁判文书数据」，本质都是对人民法院已公开文书的二次采集与加工。卖方卖的是加工、交付和授权条款，不是「官方授权」——任何自称持有「最高法官方数据授权」的卖方，都请它出示书面文件。
  2. 比价格更重要的是三件事：数据怎么来的、授权范围写没写清（内部研发 / 内嵌产品 / 对外再分发）、口径能不能核对（记录数与案件数分开报、空正文与截断如实披露）。
  3. 如果你要的其实是一份统计结论而不是原始数据，不必买授权，定制一份数据报告更便宜、更快。

二、官方有没有数据授权渠道？

中国裁判文书网由最高人民法院主办，是生效裁判文书公开的权威平台，功能定位是向社会公开、供公众查阅。截至本文写作日（2026-09-22），我们没有在其公开页面上看到面向商业机构的批量数据授权、数据销售或付费 API 的公示入口。

另据公开报道，2024 年起法院系统上线了供法院内部使用的全国法院裁判文书库；公开平台上的新增文书量从 2023 年前后明显变少，这在任何一家数据库的逐年收录曲线上都能看到。这对买家意味着两件事：

  • 「官方授权」这张牌，市场上没有人能真打出来。正规卖方的说法应当是「数据来源于人民法院公开的生效裁判文书，经我方采集、清洗与结构化」，而不是「官方授权」。
  • 2023 年以后的数据天然偏薄。任何宣称「2024、2025 年全量」的报价，都应该要求对方给出分年份的实际收录表再谈。

最终核验永远回到官方：拿到任何一家的数据，都应该能用「案号 + 法院 + 裁判日期」回中国裁判文书网抽查原文。

三、合规边界：买数据前要想清楚的四件事

以下为一般性信息整理，不构成法律意见；具体项目请咨询执业律师，并以现行有效法律法规为准。

1. 文书公开，不等于里面的个人信息可以随便用

裁判文书里有当事人、代理人、证人等个人信息。《个人信息保护法》允许在合理范围内处理已经合法公开的个人信息，但个人明确拒绝的除外，对个人权益有重大影响的仍需取得同意。落到采购上，要问卖方两件事：数据是否做过脱敏、脱敏到什么程度；收到当事人下架或更正请求时，数据怎么同步删改。没有下架机制的数据，交付之后这个义务就落到你身上。

2. 采集方式本身可能有风险

数据是怎么来的，决定了这批数据有没有「原罪」。绕过访问控制或反爬措施大规模抓取，可能引发平台规则、不正当竞争乃至计算机信息系统安全方面的法律风险。买家无法替卖方背书，但可以在合同里要求卖方对数据来源的合法性作出陈述与保证，并约定违约责任。

3. 拿去训练模型，要多一层来源说明

《生成式人工智能服务管理暂行办法》要求训练数据来源合法、涉及个人信息的依法处理。给大模型做预训练或微调的团队，采购时就要准备好将来被问到「训练数据从哪来」时能拿出来的材料：授权合同、数据来源说明、字段与脱敏说明三件套。

4. 授权范围决定价格，也决定你的边界

同一份数据，用于内部研发、内嵌进自有产品卖给终端客户、还是对外再分发给第三方，对卖方的影响完全不同，价格也不应该一样。合同里没写授权范围，等于把以后的争议留到了产品上线之后。

五、怎么核验数据是真的：签约前的 8 项检查

「海量」「全面」「领先」这些词无法核验。下面 8 项每一项都能在一两天内查完，答案的具体程度本身就能筛掉大部分卖方：

  1. 记录数与案件数分开报。同一个案件会有多份文书（一审、二审、执行、裁定），不同采集批次之间还会有重复。只报一个「N 亿篇」的，请对方同时报相异案号数。我们的口径是：总记录 160,291,678 条，相异案号约 1.27 亿——两个数一起报。
  2. 案号抽样回官方核对。随机抽 20–50 条，用案号 + 法院 + 裁判日期到中国裁判文书网查原文，逐条比对当事人、法院与裁判结果。抽样要自己抽，不要用对方挑好的样本。
  3. 要分年份、分案由的实际收录表。看 2023 年以后是否如实变薄；如果某一年突然比公开平台还多，要问清楚是怎么来的。
  4. 量空正文比例。「字段存在」不等于「有内容」——空字符串在很多检查里也算「存在」。要自己抽样量正文长度，而且按采集批次分开抽，因为空正文往往集中在个别批次。
  5. 问截断规则。超长文书有没有截断、截在哪里。判决主文常在文末，截断后「裁判结果」可能就丢了。
  6. 查重复。在一个小切片里（例如某省某年某案由）逐条比对，看完全相同的文书占多少。
  7. 试一次按当事人姓名检索。2024 年起上网文书普遍隐名，我们在四条案由链上实测，隐名比例从 2023 年的个位数到三成，升到 2025 年的九成左右（按标题判定，自选案由，非全库普查）。卖方如果承诺「按姓名查某人的全部诉讼」，请它在 2024 年以后的文书上当场演示。
  8. 问它不提供什么。一家说得清自己不提供什么（比如原文链接、胜诉率）的卖方，通常比什么都说「有」的更可靠。
我们不提供的东西，写在这里：不提供原文链接；不提供「胜诉率」——文书样本的分母问题决定了这个数算不准；不宣称「官方授权」；不承诺按当事人姓名查全 2024 年以后的文书。采购前可向商务索取当期的数据覆盖说明（分年份、分案由、分地域的实际收录情况）。

七、常见问题

Q：裁判文书数据哪里可以买到？

A：官方公开平台不出售批量数据。合规渠道是商业法律数据库机构（多为检索服务授权）和数据服务商（可交付数据本身的数据授权）。文书查提供后者：全量或按类型切分的存量数据、按月增量、API / MCP 与私有化部署，授权范围按内部研发 / 内嵌产品 / 对外再分发分别约定。

Q：中国裁判文书网有官方的数据授权或 API 吗？

A：截至 2026-09-22，我们没有在其公开页面看到面向商业机构的批量授权或付费 API 公示入口。市面上的裁判文书数据都是对公开文书的二次采集与加工，正规卖方不应宣称持有「官方授权」。

Q：买裁判文书数据合法吗？有什么合规边界？

A：裁判文书本身是公开的，但其中含有个人信息，二次使用仍受《个人信息保护法》约束；用于大模型训练还涉及训练数据来源合法性的要求。采购时要求卖方说明数据来源与脱敏方式、提供下架更正机制，并在合同中写清授权范围与来源合法性保证。以上为一般性信息，不构成法律意见。

Q：数据授权交付什么形态、包含哪些字段？

A：文书查的交付为结构化数据整批入库，或 API / MCP 调用、私有化部署。字段包括案号、法院、案由、省份、裁判日期、裁判结果和库内正文；约 91% 记录有正文，超长文书保留前 6,000 字；不提供原文链接，溯源用案号 + 法院 + 裁判日期。

Q：怎么核验卖方的数据是真的？

A：让对方分开报记录数与相异案号数；自己随机抽 20–50 条案号回中国裁判文书网核对原文；要分年份分案由的收录表；按批次抽样量空正文比例；问清截断规则；在小切片里查重复；在 2024 年以后的文书上试按姓名检索；以及问清对方不提供什么。

Q：只想要统计结果，一定要买数据吗？

A：不用。论文、课题与行业研究通常只需要统计结论，可以直接定制数据报告，每个数字附检索式，交付 Word、Excel、PPT 与图表，比买数据授权便宜得多。

Q：数据授权怎么付款、多久交付？

A：文书查按 40% / 40% / 20% 三阶段付款与交付，每阶段款项到账后 5 个工作日内交付对应比例的数据，报价含税，可开增值税专用发票。价格取决于数据范围与授权范围，提交机构接入申请后两个工作日内回复。
