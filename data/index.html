裁判文书全量数据 — 1.6 亿篇覆盖

文书查收录约 1.6 亿篇中国裁判文书,时间覆盖 1985 年至 2023 年,横跨刑事、民事、行政、执行、国家赔偿五大案件类型。数据均源自中国裁判文书网(wenshu.court.gov.cn)公开发布的生效文书,逐条保留真实案号,可回链官方原文核验。支持按案由、地域、年份、法院层级切片交付。

裁判文书数据库 — 字段结构化

原始判决书是高度非结构化的长文本。文书查把每篇文书解析成可直接入库、可检索的结构化字段:

字段说明
案号 / 法院唯一案号 + 审理法院(可定位层级与地域)
案由 / 省份标准化案由分类 + 省市,支持组合筛选
判决日期 / 审级时间维度分析、趋势统计
裁判结果支持/部分支持/驳回等结构化结果,可做胜率统计
判决全文查明 / 本院认为 / 判决主文 全文可取

裁判文书数据接口 — REST API 标准化调用

无需自建爬虫与清洗管线,一个 API 即可把裁判文书数据接进你的产品。base:https://tob.wenshucha.com/api/v1,支持关键词 + 法院 + 案由 + 年份 + 省份组合检索与全文获取,结果带 source_url 可溯源。

curl -X POST https://tob.wenshucha.com/api/v1/cases/search \
  -H "Authorization: Bearer <YOUR_KEY>" \
  -d '{"keyword":"违法解除劳动合同","province":"广东省","year":2022}'

curl 一行能验证,1 分钟接通。→ Python / Node.js 接入实战

MCP Server — 让大模型直接调用裁判文书数据

提供标准 MCP Server,Claude Desktop、Cursor 等支持 MCP 的大模型客户端可直接把裁判文书数据作为工具调用,做类案检索、案情分析、文书生成,数据可溯源、可呈堂。→ Claude Desktop 5 分钟接入

数据来源与合规

全部数据来自中国裁判文书网公开生效文书,属公开司法数据。文书查只做结构化与检索增强,当事人敏感个人信息(身份证、银行卡、手机号、邮箱)已做脱敏处理。数据用于法律科技产品、实证研究、合规分析等正当用途。
