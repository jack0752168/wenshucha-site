关于文书查

权威、稳定、易用的司法数据服务商

文书查隶属深圳星谱网络科技有限公司（CDO 成员联盟之一），是一家专注司法行业的大数据高新企业。公司旗下拥有「数据满屋」与「文书查」两大品牌——数据满屋是围绕司法数据的自营数据平台，文书查则是自主研发的、基于裁判文书数据的检索与分析系统。

自 2017 年深耕司法数据领域，我们以人民法院公开数据为来源，构建覆盖 1985 年至今、超过 1.5 亿篇的全量裁判文书数据库；通过全量打包、增量订阅与标准化 API 等方式，为政府、高校与企业提供合规、稳定、易用的司法数据底座，助力司法大数据分析、法学研究与法律科技应用。
