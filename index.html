政府 / 高校 / 律所 / AI 厂商最常问的问题

从数据来源、合规边界,到 API / MCP 接入方式与定价口径,一次说清。

文书查的裁判文书数据从哪里来?

数据均源自人民法院公开裁判文书(中国裁判文书网及各级法院公开渠道),经统一清洗与结构化处理,合法、真实、可追溯。

数据规模和时间跨度?

覆盖 1985 年至今超过 1.5 亿篇全国全量裁判文书,涵盖刑事、民事、行政、执行、国家赔偿五大类,字段结构化,每日同步更新。

API 与 MCP Server 怎么接入?

REST API 按次计费或包年套餐,提供搜索 / 详情 / 关联 / 法规 / 语义检索 / 量化预测六大接口;MCP Server 一行配置接入 Claude Desktop / Cursor / Cline 等 MCP 客户端,内置 search_cases、get_case_full_text、list_relevant_statutes、quantify_outcome 工具。海外英文版同步提供。

律师工作台能做什么?

把 1.5 亿裁判文书 + AI 接入沉淀成「类案 + 金额 + 胜率」工作台:类案精准检索、p25 / 中位 / p75 三档赔偿金额区间、胜诉率、关键裁判因素自动提取。所有数字均源自历史判决统计,链回原文可验。
